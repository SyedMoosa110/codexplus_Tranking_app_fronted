# WorkTrack Pro - Admin Web Portal

Next.js 14 Enterprise Administration & Live Employee Monitoring Portal with Tailwind CSS and Lucide icons.

## 🚀 Features
- **Live Workforce Monitoring**: Real-time status cards, active processes, and heartbeat monitoring.
- **24-Hour Visual Timeline**: Continuous time blocks (Active Work, Idle, Offline).
- **Minute-by-Minute Activity Log**: Open browser tabs, document names, and timestamps.
- **Attendance & Shift Management**: Daily work hours, overtime, and break logs.
- **Immutable Security Audit Log**: Administrative action trails.

## 🌐 Deploy to Vercel
1. Import this repository into Vercel.
2. Set Environment Variable:
   - `NEXT_PUBLIC_API_URL`: Your deployed Backend API URL (e.g. `https://api.yourdomain.com`).
3. Click **Deploy**.
